# KenzieHub — Recovery checkpoint (2026-10-12)

## Scope
This branch is **not a production-ready authentication fix**. It preserves the original design and adds a disclosed, browser-only demo for portfolio visitors. It also fixes session loading, error feedback, and modal success semantics.

## What the visitor can try
1. Open login page and click **Acessar demonstração**.
2. Create a technology, open it, edit and delete it.
3. Reload: demo profile and technologies persist in this browser.
4. Log out: the protected dashboard is no longer accessible.

Demo data stays in the current browser's localStorage. This is not real authentication; no real user accounts, server sync, or secure credentials are provided by demo mode.

CORS must allow the frontend deployment. Do not use real credentials on the legacy API until verified.
